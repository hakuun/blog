# Hakuun Blog

[![Built with Astro](https://astro.badg.es/v2/built-with-astro/tiny.svg)](https://astro.build)

Hakuun 的个人博客，记录 AI、编程、产品与日常思考。

## Tech Stack

- Astro
- Tailwind CSS
- TypeScript
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Writing

- 文章放在 `src/content/blog` 目录下
- 文章配图放在 `src/assets/blogimages/<slug>` 目录下
- 站点基础信息配置在 `src/consts.ts`
